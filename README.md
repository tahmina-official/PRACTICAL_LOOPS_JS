# ALAB 308.3.1: Practical Loops

🌐 Live Demo: 🔗 https://tahmina-official.github.io/PRACTICAL_LOOPS_JS/

This project contains three basic JavaScript exercises to practice loops, conditionals, and string handling.

## Exercises

### 1. Fizz Buzz
- Prints numbers from 1–100
- Prints "Fizz" for multiples of 3
- Prints "Buzz" for multiples of 5
- Prints "Fizz Buzz" for multiples of both

### 2. Prime Number Finder
- Finds the next prime number after a given value
- Uses loops and conditional checks

### 3. CSV Parser
## 🧠 Concept
CSV data is structured like this:

- **Rows** are separated by new lines (`\n`)
- **Columns (cells)** are separated by commas (`,`)

The program reads the string character-by-character and builds:
- A `cell` (current value)
- A `row` (array of cells)
- A `column` (2D array of rows)
